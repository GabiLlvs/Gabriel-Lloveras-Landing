# Gabriel Lloveras — Portfolio

Sitio personal. Next.js, TypeScript y CSS.

```bash
npm install
npm run dev
```

Cuando tengas el dominio de producción:

```bash
NEXT_PUBLIC_SITE_URL=https://tu-dominio
```

Eso activa la URL canónica, Open Graph absoluto y el sitemap.

Los proyectos se cargan en `src/content/projects.ts`. El perfil, la experiencia, la formación y el stack están en `src/content/`.
